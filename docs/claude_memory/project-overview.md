Project-IndexZero is a Unity-based project focused on a Lab environment featuring breadboards and circuit simulation.

**Current Focus:**
- Implementing circuit solving logic in `CircuitSolver.cs`.
- Managing visual components and UI for the lab environment.

**Collaboration Workflow:**
- Memories are stored in `docs/claude_memory/` to allow synchronization across different development machines (e.g., home and college) via Git.
- Claude will notify the user when memories are updated so they can be pushed to the remote repository.

**How to apply:** Use this as the baseline context for the project's purpose and the specific synchronization strategy for AI memory.
